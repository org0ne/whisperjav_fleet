Job priority

Hold the fleet

No agent claims a new file while the hold is on. Whatever is already transcribing runs to completion. The hold lifts by itself when the time below runs out, so a forgotten hold cannot park the fleet indefinitely.

Daily maintenance window

Every day, for this window, the fleet is held: no new files are claimed and, if ticked, files in progress are aborted and requeued. Use it to cover a SnapRAID maintenance run end to end — spin-up, sync, scrub, spin-down, probe, report — with margin. Times are the hub's local time (). The hook script only sees sync and scrub, so keep this as the floor and let the hook extend past it when a run overflows.
